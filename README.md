# SEMI-HUB v7.5 — 반도체 취업 준비 + 뉴스 + AI 취업전략

2026년 11월 2일 기준. 기업 106곳, 직무 33개, 직무적합도 검사 20문항, 연봉·채용공고·기술 지도 등 v5 기능 유지.

## 1. 바로 보기 (인터넷 연결 불필요)

`semihub_offline.html`을 Chrome/Edge로 열면 저장된 2026년 기사 48건과 기술 설명을 볼 수 있습니다. 검색/출처별 필터/월별 필터/교육 해설/원문 링크가 작동합니다.

**주의: HTML 파일 하나만 열면 자동 수집·AI 호출이 되지 않습니다.** 뉴스 데이터는 HTML 생성 시점의 목록이며 자동으로 바뀌지 않습니다.

## 2. 인터넷 연결 + 6시간마다 자동 수집 (0·6·12·18시)

1. Python 3 설치: https://www.python.org/downloads/
2. ZIP 전체 압축 해제 후 `start_semihub.cmd` 더블클릭. `http://127.0.0.1:8765/`가 열립니다. 기존 프로그램이 8765 포트를 사용하면 **8766~8769 포트**가 선택되므로 실행 창에 표시된 주소를 확인하세요.
3. 웹사이트 → 최신 기술·이슈 → `↻ 최신 뉴스 수집` 클릭 시 수집이 시작됩니다. 창을 열어둔 상태에서는 **6시간마다(한국시간 0·6·12·18시)** 자동 수집이 시작됩니다.
4. **서버를 계속 켜놓을 수 없다면** `install_every6h_windows.bat` 실행 후 Windows 작업 스케줄러에 `SEMIHUB_DailyNoon`(6시간 반복) 등록. Windows 시간대가 `(UTC+09:00) 서울`로 설정돼 있어야 합니다. 실행 시각은 시작 시간이며, PC가 꺼져 있으면 즉시 실행할 수 없습니다(가능하면 다음 부팅에 실행).
5. 예약 명령은 `update_once_windows.bat` → `updater.py`이며 기업 채용·기존 뉴스와 새 국제 뉴스 수집 모두 갱신합니다.

## 3. 2026년 기사 수집 범위

- 한국 주요 매체: **조선비즈, 조선일보, 전자신문, 디일렉, ZDNet Korea, 디지털데일리, 연합뉴스, 매일경제, 한국경제, 서울경제**.
- 해외 주요 매체: **Reuters, Semiconductor Engineering, EE Times, TrendForce, DigiTimes, Tom’s Hardware, eeNews Europe, IEEE Spectrum, Semiconductor Digest**.
- 기업 공식 뉴스: **SK hynix, Samsung, TSMC, ASML, Applied Materials, Intel, Micron** 등.
- 공개 Google News RSS 검색으로 **국내 주제 18개, 해외 주제 12개, 매체·뉴스룸별 26개** = 56개 검색 축 + 공개 RSS 4종을 처리합니다.
- 매일: 최근 4일~현재 기사 검색 + **2026년 1월부터 해당 월까지의 월별 과거 기사 검색**을 40건씩 이어서 실행합니다. 방문자가 웹 UI의 `⊞ 2026 과거 기사 더 수집` 버튼을 누르면 70건씩 추가 검색을 예약합니다.
- 2026년 11월 2일 기준 과거 검색은 최대 616개 검색 작업입니다. 완료 여부는 `news_state.json`에 저장되며 성공한 작업만 완료로 표시합니다.
- 신규 기사만 `news_archive.json`에 중복 제거해 추가하고, 검색일이 아닌 **언론사 발행일** 기준 최신순으로 정렬합니다. 누적 최대 12,000건(향후 설정 조정 가능).
- 첫 실행 시 인터넷에서 실제 RSS가 수신되어야 수집됩니다. 서비스가 제공하지 않는 과거 기사, 검색 인덱스에서 누락된 기사, 비공개·유료 기사, URL 차단 기사까지 100% 수집할 수는 없습니다.
- 최신 수집과 과거 검색은 중단되어도 기존 누적 기사를 지우지 않습니다. 로컬 전용 API `/api/technews`로 전체 데이터 조회.

## 4. 기사 자동 해설 및 무료 AI

- **기사 등록 직후** 기사 제목/짧은 RSS 요약을 기준으로 기술 카테고리를 자동 분류하고, 기술 원리 → 제조 공정 연결 → 공부할 키워드를 정리한 **규칙 기반 무료 학습 설명**을 모든 기사에 제공합니다. AI 키가 없어도 작동합니다.
- Google Gemini API의 **무료 등급(사용량 제한)**을 원하면 환경변수 `GEMINI_API_KEY`에 본인이 발급한 키를 설정하세요. 모델 기본 `gemini-3.5-flash-lite` (실제 이용 가능한 모델과 무료 정책은 개발사 정책에 따릅니다). 더 맞는 모델을 쓰려면 `GEMINI_MODEL` 환경변수 변경.
- 예약 실행(6시간마다)에서 환경변수 API 키가 있으면 신규 기사부터 **실행당 최대 12건**을 자동 AI 분석해 `news_archive.json`에 저장합니다. 비어 있는 이전 기사의 해설도 다음 실행에 제한적으로 채웁니다. `AUTO_AI_MAX`로 실행당 분석 건수를 조절할 수 있으나 무료 한도를 초과하지 않도록 주의하세요.
- UI의 `API 키 입력`은 실행 중인 **로컬 서버 메모리용**이므로, Windows 작업 스케줄러가 실행하는 **별도 Python 프로세스**에는 전달되지 않습니다. 예약 자동 분석에는 `GEMINI_API_KEY` 환경변수를 사용해야 합니다.
- 키 미설정·한도 초과·API 오류가 나도 RSS 수집 및 규칙 기반 해설은 계속 유지됩니다. Gemini 무료 티어에서 제출 자료가 제품 개선에 사용될 수 있으니 회사 내부정보·개인정보를 입력하지 마세요.

## 5. 저작권 및 출처

기사 전문은 저장하지 않습니다. RSS로 제공된 제목·날짜·발행사·원문 링크·짧은 공개 텍스트만 저장하며, 분석은 제목/짧은 설명으로 만든 **독립적인 학습 글**입니다. 실제 사건의 세부사항이나 수치를 원문까지 읽고 검증한 결과는 아닙니다. 원문 보도를 확인해야 하며, 전문 재게시/로그인 우회/유료 기사 무단 복제는 지원하지 않습니다.

## 6. 프로젝트 주요 파일

`index.html` UI 시작점; `tech-ui.js` 뉴스/기술 검색 및 해설; `tech-data.js` 초기 48개 기사와 18개 기술; `news_engine.py` 광범위 RSS·과거 기사 수집·중복 제거·자동 분석; `news_archive.json` 수집 기사 누적 저장; `news_state.json` 검색 진행 상태; `updater.py` 기존 채용/뉴스 포함 통합 수집; `server.py` 로컬 서버·API; `ai_local.py` Gemini 호출; `make_offline.py` 로컬 미리보기 HTML 생성; `install_daily_noon.ps1` Windows 낮 12시 예약.

**주의:** `news_archive.json`, `news_state.json`은 최초 설치 시 비어 있으며, 인터넷이 연결된 로컬 실행 환경에서 수집 시에만 채워집니다. 이 개발 환경은 외부 RSS 접속이 차단되어 실제 대량 수집을 검증하지 못했습니다.

## 7. 기업 공식 채용 사이트 자동 수집 (대기업·장비사)

`updater.py`(6시간마다 도는 작업)가 아래를 함께 실행합니다. 결과는 「2026 채용공고」 화면에 합쳐지고, 하단 **수집 현황** 패널에 기업별 성공/실패가 표시됩니다.

| 수집기 | 대상 | 방식 |
|---|---|---|
| samsung | 삼성전자(DS/DX 구분은 원문 확인)·삼성전기 | samsungcareers.com 공고 목록 |
| skcareers | SK하이닉스·SK실트론·SK키파운드리·SK플라즈마 등 | skcareers.com JSON |
| hynix_hub | SK하이닉스 인재허브(본사 공고) | talent.skhynix.com HTML |
| dbhitek | DB하이텍 | dbhitek-recruit.com |
| lam / amat | 램리서치·어플라이드머티어리얼즈 한국 | Eightfold 공개 검색 API |
| kla | KLA 한국 | Workday API |
| asml | ASML 코리아 | Sitecore Search(토큰 발급 후 조회). **Playwright가 있으면 실제 크롬으로**, 없으면 일반 HTTP로 시도 |
| tel | 도쿄일렉트론코리아 | recruiter.co.kr 채용 사이트. 화면 렌더링 방식이라 **Playwright 필수**(없으면 오류로 표시) |

- **나머지 기업**은 `companies.json`의 채용 페이지 주소로 **변경 감지**(`career_watch.py`)만 합니다. 공고를 읽는 것이 아니라 "페이지가 바뀜"을 알려 줍니다. 자바스크립트로 목록을 그리는 페이지는 감지가 불가능해 패널에 `감지 불가`로 집계됩니다. (ASML·TEL은 위 전용 수집기로 처리).
- 어떤 수집기가 실패해도 다른 수집기와 **이전 수집 결과는 유지**됩니다(공고가 사라진 경우에만 해당 수집기 결과가 교체).
- 마감일이 표시되지 않는 상시 공고(Lam·AMAT·KLA)는 「상시·마감일 미표시」로 보이고 "마감일 미경과" 필터에 포함됩니다.
- **처음 한 번은 직접 확인하세요:** `python job_collectors.py` 를 실행하면 수집기별로 `[OK]`/`[ERR]`와 건수가 출력됩니다(live.json은 변경되지 않음). 사이트 구조는 예고 없이 바뀔 수 있어서, `[ERR]`가 나오면 그 줄의 오류를 알려 주세요.
- 오프라인 테스트: `python test_collectors.py` (2026-11-02에 관찰한 실제 응답 모양 기준). 사이트 개편은 이 테스트로 잡히지 않으므로 위 실행 확인이 필요합니다.
- 알려진 한계: SK하이닉스 인재허브·DB하이텍은 개발 시점에 공고가 0건이라 **공고가 있을 때의 응답을 확인하지 못했습니다**. 형식을 해석하지 못하면 조용히 비우지 않고 오류로 표시합니다.
- **ASML(Playwright):** 처음 한 번 `install_playwright_windows.bat`을 실행하면 브라우저(약 150MB)가 설치됩니다. 설치하지 않아도 일반 HTTP로 먼저 시도하지만, ASML이 스크립트 요청을 막으면 실패합니다. 둘 다 실패하면 수집 현황에 사유가 표시되고 **이전 수집 결과는 유지**됩니다. ASML 채용 페이지는 자바스크립트 전용이라 '변경 감지'로는 대체할 수 없습니다.

## 8. 취업 준비 도구 (v6 추가)
| 메뉴 | 내용 |
|---|---|
| 지원 현황 | 공고별 상태(관심→최종합격), 마감 D-day, 메모. 채용공고 카드의 "지원 추적" 버튼 또는 직접 추가. 마감 3일 이내 공고는 대시보드·지원 현황 상단에 표시 |
| 면접 준비 | 기술면접 질문은행(83문항, 설계 51문항 · 답 숨김, 알겠음/모르겠음 반복), 자소서 보관함(회사별 문항·답변, 글자 수 세기, 검색·복사로 재사용), 직무 트랙별 로드맵 체크리스트, 기업별 노트 |
| 내 스펙·진로 | 직무 선택 → 로드맵 진행·내 스펙 키워드 비교(갭 분석), 취업 vs 대학원 누적 소득 계산기(입력값 기반) |
| 최신 기술·이슈 | 기사 상세에 "나의 1분 면접 답변" 입력란(기사별 자동 저장) |

- 모든 개인 데이터는 **브라우저 localStorage**에만 저장됩니다. 같은 주소(예: 127.0.0.1:8765)로 접속해야 같은 데이터가 보이며, semihub_offline.html(file://)과는 저장소가 따로입니다. 지원 현황 화면 아래 "내 데이터 백업"으로 내려받기/불러오기를 하세요.
- 질문은행 답변은 교재 수준의 일반 설명이며 실제 출제나 회사별 정답을 보장하지 않습니다. 서류 합격 커트라인은 회사가 공개하지 않아 점수 판정은 하지 않습니다.
- 취업 vs 대학원 계산기의 기본값은 예시입니다. 본인 값으로 바꿔서 쓰세요.


## 9. 카카오톡 알림 ("나에게 보내기")
새 공고와 채용 페이지 변경이 감지되면 카톡 "나와의 채팅"으로 알려줍니다. 업데이트(`updater.py`)가 돌 때마다 확인합니다.
1. developers.kakao.com → 앱 만들기 → REST API 키 복사
2. 카카오 로그인 활성화, Redirect URI에 `http://localhost:5000/callback` 추가, 동의항목 "카카오톡 메시지 전송(talk_message)" 설정
3. `setup_kakao_windows.bat` 실행 → 열린 `kakao_config.json`에 키 입력 → 다시 실행해 안내대로 로그인
4. 연결되면 카톡으로 테스트 메시지가 옵니다. 이후 `python kakao_notify.py test`로 다시 시험할 수 있습니다.
- 처음 실행 때 이미 있는 공고는 알림을 보내지 않고 기준선으로만 저장합니다(알림 폭탄 방지).
- 전송이 실패하면 다음 업데이트 때 다시 시도합니다. 설정이 없으면 알림 기능은 조용히 꺼져 있습니다.
- `kakao_config.json`, `kakao_token.json`은 비밀번호처럼 다루고 공유하지 마세요.
- 지원 현황의 마감 D-day 알림은 데이터가 브라우저에만 있어 아직 카톡으로는 가지 않습니다.


## 10. v7 개인화 기능 (오늘 / 내 프로필 / 알림)
1. **내 프로필·스펙**에서 신입/경력, 관심 직무·기업, 보유 기술을 한 번 입력합니다.
2. 첫 화면(**오늘**)에 임박 마감, 내 관심 공고·뉴스, 오늘 복습할 질문이 모입니다.
3. 채용공고·기술 뉴스의 **내 관심만** 체크로 내 조건에 맞는 것만 봅니다.
4. 뉴스 상세의 **내 관점 분석**, 질문의 **모의 면접**은 Gemini 무료 키가 필요합니다 (서버 실행 시).
5. **지원 현황**에서 전형 단계를 기록하고 **캘린더(.ics) 내보내기**로 휴대폰 캘린더에 넣을 수 있습니다.
6. 카카오톡 알림은 내 프로필 조건으로 새 공고를 거르고, 일정(D-3·D-1)과 관심 뉴스 요약도 보냅니다. 미리 보기: 내 프로필 → 알림 미리 보기.
7. 개인 데이터는 `user_data.json`(+ `user_backups/` 하루 1회 백업)에 저장됩니다. 서버 없이 열면 브라우저 저장소만 사용합니다.

### v7.5 추가
- 자동 갱신: **6시간마다(한국시간 0·6·12·18시)**. 서버를 켜 두면 자동, 서버 없이 쓰려면 `install_every6h_windows.bat`(작업 스케줄러에 6시간 반복 등록). 최근 5시간 안에 성공한 갱신이 있으면 건너뜁니다.
- **AI 취업전략 카톡 요약**: 내 프로필·스펙 → 「AI 요약 받기」를 켜고, `GEMINI_API_KEY` 환경변수와 카톡 연결이 있으면 갱신 때 관심 뉴스를 3줄(200자)로 요약해 보냅니다. 같은 기사는 1회, 하루 최대 4건. 기술·경험 전송은 별도 동의 체크가 있을 때만.
