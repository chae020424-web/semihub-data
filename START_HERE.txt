SEMI-HUB v7.5 — 실행 안내 (Windows)

[방법 1: 설치 없는 화면 바로 보기]
- semihub_offline.html 파일을 Edge / Chrome으로 여세요.
- 기업 탐색, 반도체 직무, 직무 적합도 20문항, 채용공고,
  2026 반도체 기술 뉴스와 기술 설명을 사용할 수 있습니다.
- 이 방식은 새로운 뉴스 자동 수집 및 무료 AI 분석 기능을 사용할 수 없습니다.

[방법 2: 인터넷 뉴스 자동 갱신 + 무료 Gemini AI]
1. Python 3 설치: https://www.python.org/downloads/
2. 이 폴더에서 start_semihub.cmd 를 더블클릭합니다.
3. 브라우저가 자동으로 열리지 않으면 콘솔에 표시된 http://127.0.0.1:8765/ 주소를 여세요.
   기존 웹사이트가 포트를 사용 중이면 8766~8769번으로 자동 변경됩니다.
4. 「최신 기술·이슈」 → 「새 소식 가져오기」 버튼으로 최신 기사 수집을 시작합니다.
5. 원하는 기사 제목 → 「AI 분석 실행」 → 무료 API 키 설정
   https://aistudio.google.com/api-keys 에서 받은 Gemini 무료 키를 입력하세요.
   API 키는 현재 PC의 서버 메모리에만 남고 파일에는 저장되지 않습니다.

[6시간마다 자동 갱신 (0·6·12·18시)]
- 로컬 서버를 계속 켜 두면 6시간마다 RSS 수집·공고·카톡 알림을 갱신합니다.
- 서버를 닫아도 6시간마다 수집하려면 install_every6h_windows.bat을 실행하고
  Windows 작업 스케줄러에 등록합니다. PC가 켜져 있어야 합니다.
- 시스템 날짜/시간대: 한국(UTC+09:00) 설정을 확인하세요.

저작권 안내: 기사 전체 복사가 아닌 제목·날짜·원문 링크 + 독립 교육 해설입니다.
AI 분석은 기사 전문 읽기가 아니라 공개된 제목·요약·연관 기술에 기초합니다.
